# Agent Note: SCYS Saved-Grant Reconnect Cooldown

Status: implemented

English | [中文](2026-10-14-scys-saved-grant-reconnect-cooldown.md)

## Problem

一次已保存授权重连失败会在整个 Host 生命周期内被缓存。网络或服务暂时故障恢复后，后续来源状态请求仍无法重新连接，用户只能进入交互式 OAuth 操作。

## Decision

SCYS Adapter 保留 single-flight 重连，只在已分类的临时网络错误以及 HTTP 408、425、429 或 5xx 发生后，等待 Host 内存冷却期，再由后续状态请求触发重试。间隔依次为两分钟、四分钟、八分钟，最长十五分钟。重连成功会清除退避状态。授权记录缺失或无效、回调注册错误及授权失败不会自动重试；重试不会启动 OAuth，也不会修改凭据。

## Alternatives considered

- **每个 Host 生命周期只尝试一次** — 虽可阻止重复请求，但暂时故障会让有效的已保存授权永久无法恢复。
- **每次状态请求都重试** — UI 轮询时可能频繁初始化 MCP，服务故障期间也无法限制请求量。
- **启动后台定时重试** — 即使没有后续状态检查也会发起网络请求，还会增加信息流不需要的生命周期逻辑。
- **使用 OAuth 连接操作恢复** — 该操作会启动交互式授权，因此不能作为已保存授权的普通重连机制。

## Consequences

只有应用在冷却期后再次请求来源状态时，Adapter 才会重连。冷却期间保留脱敏失败诊断，不会把通用不可用状态推断为授权失效。重新授权仍是用户主动操作。退避状态仅存在于当前进程，新 Host 启动后重置。
