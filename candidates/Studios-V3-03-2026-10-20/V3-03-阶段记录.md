# Studios V3-03 阶段记录

## 范围

基于 `Studios-V3-02R-2026-10-20` 建立独立 V3-03 候选。本阶段为 Video Packaging 增加模型目录读取、字幕输入与包装建议审核入口；复用现有工程、时间轴、素材、保存和 FFmpeg 渲染机制。没有修改正式 Desktop、正式 3080 Host、正式 DSH_HOME、R1/R2/V2/V3-01/V3-02R 候选，也没有请求真实媒体或语言模型。

## 结果

- **UI / Host 集成：实现并构建通过。** 顶部新增「AI 智能包装」入口；侧栏包含模型状态、字幕状态、素材库/自由创作模式、创作要求、方案预览和人工审核。方案可逐项选择，只有确认项进入当前工程；拒绝方案不改时间轴。SRT/VTT 仍使用现有导入和解析能力。
- **模型配置发现：真实 Host Remote 通过。** 从当前隔离 Host 的 LLM Provider/Model registry 只读读取到 `deepseek-official/deepseek-v4-flash`、`deepseek-official/deepseek-v4-pro`、`deepseek-official/deepseek-v4-flash-vision-exp`。这仅表示注册表列出模型，不代表认证可用或已调用。
- **模型调用：未就绪，未运行。** 当前没有专用、受约束的 Video Packaging Agent 路由；认证状态未检查。模型项显示不可调用；未复用 XHS `restrictedAgent`、`commentAnalysis` 或媒体生成 Provider。没有发送模型请求，MODEL REAL = NOT RUN。
- **规则演示：明确标记 Fixture。** 自由创作模式当前为本地规则 Fixture，不是模型推理；素材库模式只检索用户确认且许可明确的素材。无合格素材时显示空结果；测试素材不会自动晋升。
- **校验与时间轴：聚焦测试通过。** 测试覆盖重复建议 ID 拒绝、选择性应用、已有组件保留；应用前校验字幕证据、时间范围、组件类型、画布范围及重叠规则。项目中的审核草稿重新打开时重新校验。
- **Host 持久化与渲染：隔离真实 Host PASS。** Remote 创建并读取测试工程，工程修订为 2 且包装组件存在；Host FFmpeg 输出由 Host 管理。隔离 Host 重启后工程、素材引用及已完成 Render Task 均恢复。输出文件为 `runtime/acceptance/fixture-render.mp4`，ffprobe 验证 H.264、1280×720、8 秒，AAC、48 kHz、单声道、8 秒。该验证使用合成测试视频及测试透明 PNG，不含私人素材；真实媒体 Provider 请求数为 0。
- **Client 构建：通过；实际页面交互：PARTIAL。** Client Bundle 和 Web Bundle 构建通过。Headless Chromium 加载候选页面根节点，但首次运行提示和工作区/会话选择浮层遮挡了 Studios 导航，因此没有取得 AI 面板完整交互截图；不将此标记为真实浏览器 UI PASS。正式 Client 对话/会话数据未使用。
- **Host 停止：PASS。** 验证 Host 的隔离监听端口已正常释放；正式 3080 不受影响。
